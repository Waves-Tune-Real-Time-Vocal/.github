# Waves Tune Real-Time Vocal

Waves Tune Real-Time is a vocal pitch correction plugin designed for recording sessions and live performances. It adjusts incoming vocal notes as they are performed, allowing singers, producers, and engineers to monitor the tuning effect without waiting for a separate editing stage.

The plugin provides control over musical scales, correction speed, note transitions, and vocal characteristics. Its processing can support subtle intonation adjustments or a more pronounced, tightly tuned vocal sound, depending on the chosen settings.

## Overview

Waves Tune Real-Time analyzes incoming vocal pitch and applies correction according to the selected musical settings. Unlike workflows based entirely on editing recorded notes afterward, it allows performers to hear the processed signal while tracking.

The plugin is suitable for studio production, vocal monitoring, and supported live audio setups. Its behavior depends on the selected scale, correction parameters, input signal, and host configuration.

## Vocal Tuning Workflow

### Input and Monitoring

Route the vocal signal through a compatible audio host and configure the appropriate input and output devices. Monitor the processed signal to evaluate the correction and overall vocal character.

### Scale Configuration

Select the musical scale that matches the song. Custom scale settings can help accommodate particular melodic requirements and musical traditions.

### Correction Settings

Adjust the correction speed and transition behavior according to the performance. Faster correction can produce a more pronounced tuning effect, while more gradual settings can retain a less processed character.

### Performance Review

Listen for changes in articulation, note transitions, vibrato, and overall musical expression. Settings that work for one singer or song may not suit another, so evaluate them in context.

## Typical Applications

### Studio Recording

Apply pitch correction during vocal tracking so the performer can hear the adjusted sound while recording. This can help establish the intended vocal character early in the production process.

### Live Vocal Processing

Use a compatible live audio system to process vocals during performance. Low or near-zero processing latency depends on pitch, audio configuration, and the overall signal path.

### Pop and Electronic Vocals

Use stronger correction settings when a tightly tuned or deliberately synthetic vocal character fits the arrangement.

### Natural Vocal Refinement

Choose settings that support more restrained correction when preserving the singer's expression and phrasing is important.
